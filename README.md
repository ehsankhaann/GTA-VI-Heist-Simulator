# GTA VI Heist Simulator — Vice City Edition

An interactive web version of the original console script `2- GTA VI Heist Simulator.js`.

## What's in this folder

| File | Purpose |
| --- | --- |
| `index.html` | The web app — open this file in any browser |
| `styles.css` | GTA VI / Vice City neon theme and animations |
| `app.js` | Interactive logic (same conditions and message text as the original) |
| `original-copy.js` | Untouched copy of the original console script |

The original file at `D:\0043- Web Development Journey\03- Projects\d- Small Projects (learning phase)\a- Code Files\2- GTA VI Heist Simulator.js` was **not modified**.

## How to run

Double-click `index.html` (or drag it into Chrome / Edge / Firefox). No server, install, or internet connection is needed.

## How to play

1. Slide **Cash on hand** to set your money.
2. Toggle **Gateway Car**, **Partner** and **Weapon** (starts at the original defaults: $15,000, car ✓, partner ✗, weapon ✓).
3. Hit **START HEIST** to watch the mission control log run the original checks with a typewriter effect.
4. `DEFAULTS` restores the original values; `CLEAR LOG` wipes the terminal.

A successful run triggers confetti and a neon flash; a blocked run shakes the app. The checklist and status pill update live as you change the setup.
